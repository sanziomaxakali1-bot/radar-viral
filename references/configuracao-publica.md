# Configuração pública de vozes

A versão pública não assume as vozes do criador. Ao abrir `Configurar voz`, pergunte se o cliente quer voz original,
ElevenLabs ou outro provedor. Para ElevenLabs, explique o onboarding oficial e peça somente os IDs das vozes escolhidas;
nunca peça API key no chat.

Salve os IDs por personagem no estado do projeto. Para um robô, gere a fala e aplique o efeito robótico depois, somente
na faixa do robô. Gere uma amostra curta, remova silêncios e respirações excessivas, peça aprovação e só então produza
o vídeo completo.

As vozes usadas no projeto pessoal anterior são apenas um exemplo e não são padrão obrigatório para clientes.
