# Radar Viral

Skill pública para pesquisar tendências, transformar ofertas em Reels e conduzir a produção de vídeos falados, sem rosto, híbridos e 3D.

## O que faz

- pesquisa padrões de Reels públicos por nicho;
- analisa gancho, copy, mecanismo, prova, ritmo, cortes e CTA;
- cria briefing, roteiro e plano de cenas;
- configura vozes por projeto;
- usa `animador-zero` quando disponível para vídeos 3D;
- gera prévia antes do render completo;
- revisa áudio, legendas, cortes e arquivo final;
- trabalha com estado salvo para reduzir tokens.

## Instalação

Leia [SETUP.md](SETUP.md) e rode `scripts/setup.ps1` no Windows.

Depois, ative a skill com `$radar-viral`.

## Segurança

Não inclua API keys, OAuth, tokens, vídeos pessoais ou projetos privados no repositório. As vozes são configuradas pelo cliente dentro do projeto.
